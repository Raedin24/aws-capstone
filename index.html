Project Overview

What We Built

A cloud-hosted web application deployed on AWS, running on an Amazon EC2 instance with Ubuntu and Apache Web Server. An Application Load Balancer distributes traffic, CloudWatch provides monitoring and alerting, and GitHub Actions automates deployments through a CI/CD pipeline.

Goals

Project Objectives

Deploy on AWS

Host a production-ready web application on AWS infrastructure.

Secure Access

Implement IAM roles and MFA for least-privilege access control.

CI/CD Pipeline

Automate deployments using GitHub Actions workflows.

Monitor Infrastructure

Track system health and performance via Amazon CloudWatch.

Cost Management

Control spend with AWS Budgets and threshold notifications.

Best Practices

Demonstrate AWS Well-Architected Framework cloud principles.

Infrastructure

AWS Services Used

Amazon EC2

Hosts the web application using Ubuntu 22.04 and Apache Web Server.

Application Load Balancer

Distributes incoming traffic across instances and performs health checks.

Amazon S3

Stores static assets, deployment artifacts, and project files.

AWS Certificate Manager

Provides SSL/TLS certificates for secure HTTPS communication.

Amazon CloudWatch

Monitors system performance metrics and generates operational alerts.

AWS Budgets

Tracks project spending and sends notifications when thresholds are exceeded.

IAM

Provides secure access control with least-privilege permissions and MFA.

GitHub Actions

Automates application deployment through a CI/CD pipeline on every push.
